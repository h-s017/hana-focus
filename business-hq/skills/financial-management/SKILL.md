# financial-management
版本：1.1.0｜繁體中文
## 工作流程
1. 取得已確認的數量、單價、稅別、成本、付款條件及期間；統一 TWD 與計量單位。
2. 營收=未稅單價×數量；毛利=營收−直接銷貨成本；貢獻毛利=營收−全部變動成本；毛利率=毛利÷營收（零營收時不適用）。
3. 另列固定成本、開發費、人工、運費、損耗、包裝、稅及回款時間；未知成本為 null，不是 0。損益兩平量=固定成本÷單位貢獻（須為正）。
4. 建立基準/不利/有利情境，及13週現金預測；營收不等同收款，現金期末=期初+流入−流出。
5. 不自動承諾報價、付款或改帳；稅務以台灣財政部最新規範及專業確認為準。
## 持續價值與收入驗證
分列首次開發收入、後續供貨/補貨、跨品類擴充及持續服務收入；每項確認付款人、頻率、合約責任、貢獻毛利及現金回收。不能把一次性開發費視為經常性收入，也不假設客戶必然續購。依 corporate-strategy 三層業務組合區分實收、已簽約及假設收入，為種子實驗設定損失上限與停止條件；不以預估規模替代可得訂單。
## 交付與驗收
可追溯公式、成本來源、毛利及現金缺口；必填缺漏阻擋正式報價。

## 共通執行規則
- 先辨識目標、已授權的資料來源、可用工具及缺漏；不虛構來源、價格、客戶或成功狀態。
- 事實附來源與取得日期；估算列公式、假設與敏感度；未知值標記待驗證。
- 只在授權範圍執行；對外寄送、付款、發布、改正式資料需獨立核准。私有資料不得進入公開 GitHub 或未授權模型。
- 回傳結構：goal、skill_version、sources、assumptions、deliverables、metrics、blockers、next_actions、approval_required。成果附實際檔案或紀錄 ID；無工具則標記 blocked，不以草稿冒充執行。
