# 社群圖像品質修正：待審核

## 問題與處理

目前預覽的 2026-10-27「氣味設計為何需要節奏？」共有六頁，但原 PowerPoint 與 HTML 產生器只有文字及固定深色幾何圖形，沒有真正的插畫。每日教材雖有風格欄位，未帶入匯入素材；原成功狀態也只驗證技術匯入，不能代表視覺品質。

此修正移除幾何佔位圖的完成路徑。缺少圖像時保留文案，標示視覺未完成，不建立新 PPTX。既有檔案及 Canva 設計不會刪除或覆寫。

## 圖像與匯入契約

在當日 `content/instagram/YYYY-MM-DD/` 放置 `artwork.json` 與六張圖像，才可建置：

- `format: hana-social-artwork-v1`，日期、標題、風格必須對應同版教材。
- `origin: new_original_artwork`、`generation_mode: individual_images`。
- 每個 `items` 項目包含相對路徑 `file`、實際 `sha256`、不同的 `generation_id`。
- 六張 PNG/JPEG/WebP，至少 1080×1350，比例接近 4:5，各不超過 8 MiB。拒絕重複圖像、格狀拼圖模式與目錄外路徑。
- 產生的 PPTX 有六個原生圖片層與可編輯文字。教材記錄圖像及 PPTX 摘要，`human_review: pending`、`publication_authorized: false`。
- 服務端匯入前須有六張圖像的完整記錄，下載並核對同版 PPTX 摘要；以 20 MiB 限制標頭及串流大小。

這些屬於結構與版本檢查。圖像來源欄位是提交者聲明，不能自動證明原創、授權、無禁用主題或美感；HANA 仍須逐頁檢查。Canva 匯入成功僅表示技術完成，介面明示視覺待審核。

## 驗證與限制

- 本地 31 個 Node 測試檔、語法檢查與網站建置通過。
- Python 四項測試涵蓋缺圖、測試素材隔離、六張獨立圖片及可編輯文字、錯誤日期／風格／摘要／重複圖像／格狀圖／低解析度。
- 匯入測試涵蓋缺圖、測試素材、重複摘要、不同 PPTX 版本、超大標頭及串流；成功仍須人工審核。
- 兩組模擬瀏覽器測試通過，涵蓋 320／390／820 寬度。最初因瀏覽器快取路徑未設定失敗，指定既有 `PLAYWRIGHT_BROWSERS_PATH` 後重測通過，未變更正式登入或資料。
- CI 使用明確標記的純色測試圖片；僅驗證檔案結構，不可當成真實社群成品，正式工作流程拒絕這類素材。
- 六張新版插畫、排版 PNG、PDF 與 PPTX 留在私人交付包；未提交公開 GitHub。PDF 為瀏覽器排版預覽，尚未完成 Canva 字型及排版驗證。
- 本次沒有啟用付費 API、IG／FB 發布或生產環境部署。每日自動產圖工具仍未接通；本次圖像是獨立製作，不能宣稱每日自動化已完成。

## 審核、上線與回復

1. HANA 檢視私有六頁預覽；Canva 上傳仍需明確授權。保留現有預覽作為歷史版本。
2. 審核此 PR 及 exact-head Actions 結果後，另行核准合併、網站與 Edge 發布。此 PR 不含資料庫 Migration 或秘密憑證變動。
3. 測試無圖教材顯示未完成、有合格圖像才可匯入；逐頁核對 Canva 字型及換行。Instagram 發布始終另行核准。
4. 如需回復程式，回復此 PR 的 commit 並重新部署先前已審核版本；不需要刪除任務、訂單、素材或 Canva 設計。回復舊程式會恢復缺圖檢查漏洞，應同時停用原每日 Canva 匯入排程，直到修復。
