# 社群圖像與原 Canva 版型修正：待審核

## 問題與處理

目前預覽的 2026-10-27「氣味設計為何需要節奏？」共有六頁，但原 PowerPoint 與 HTML 產生器只有文字及固定深色幾何圖形，沒有真正的插畫。每日教材雖有風格欄位，未帶入匯入素材；原成功狀態也只驗證技術匯入，不能代表視覺品質。

此修正移除幾何佔位圖的完成路徑。缺少圖像時保留文案，標示視覺未完成，不建立新 PPTX。既有檔案及 Canva 設計不會刪除或覆寫。

2026-10-28 HANA 再次指出不符合預設。重新核對發現規格前段仍寫「預設紙白水彩」，與後面的最新規則「每天可不同，同日單一風格」衝突；前次新製的水彩 PPTX 也採用自行指定的字型、字級及位置，未實際沿用原 Canva 版型。因此該六頁仍需重做，不能以圖片已產生或測試通過視為驗收。

已唯讀檢查原參照 `DAHYaVlqYOg` 與工作版 `DAHYaeidsPw`。後者實際五頁，不能沿用舊文件的「已存在六頁模板」說法。沒有複用原照片、修改或儲存原設計。

## 圖像與匯入契約

在當日 `content/instagram/YYYY-MM-DD/` 放置 `artwork.json` 與六張圖像，才可建置：

- `format: hana-social-artwork-v1`，日期、標題、風格必須對應同版教材。
- `preset_id: hana-art-editorial-2026-10-20`、`layout_reference_design_id: DAHYaeidsPw`。規則集中在 `social-editor/visual-preset.json`，不再有固定媒材／配色預設。缺少當日風格或使用別的模板會拒絕建置。
- `origin: new_original_artwork`、`generation_mode: individual_images`。
- 每個 `items` 項目包含相對路徑 `file`、實際 `sha256`、不同的 `generation_id`。
- 六張 PNG/JPEG/WebP，至少 1080×1350，比例接近 4:5，各不超過 8 MiB。拒絕重複圖像、格狀拼圖模式與目錄外路徑。
- 產生的 PPTX 有六個原生圖片層與可編輯文字。教材記錄圖像及 PPTX 摘要，`human_review: pending`、`publication_authorized: false`。
- 服務端匯入前須有六張圖像的完整記錄，下載並核對同版 PPTX 摘要；以 20 MiB 限制標頭及串流大小。
- 自訂 PPTX 建置器一律輸出 `layout_status: draft_relayout`，保留既定版型 ID 與當日風格，不能自行宣稱套版完成。服務端對非 `native_reference_preserved` 狀態回報 `layout_reference_required` 並停止新匯入；介面顯示原版型尚未套用。

**目前沒有完成原生 Canva 套版的產製路徑。** 因此上述檢查部署後，現有自訂 PPTX 不能再自動送成今日成品；需要完成保留原字體與位置的 Canva 工作流程、逐頁驗證後才能恢復。不能手動改一個狀態字串作為解鎖方式。

這些屬於結構與版本檢查。圖像來源及版型狀態欄位是產製紀錄聲明，不能自動證明原創、授權、實際字型、無禁用主題或美感；HANA 仍須逐頁檢查。Canva 匯入成功僅表示技術完成，介面明示視覺待審核。

## 驗證與限制

- 本地 31 個 Node 測試檔、語法檢查與網站建置通過。
- Python 六項測試涵蓋缺圖、測試素材隔離、六張獨立圖片及可編輯文字、錯誤日期／風格／摘要／重複圖像／格狀圖／低解析度、缺少風格或錯誤模板，以及缺圖時保留當日風格與版型規則。
- 匯入測試涵蓋缺圖、測試素材、重複摘要、不同 PPTX 版本、超大標頭及串流，以及自訂排版、缺少版型狀態、舊預設與錯誤模板；成功仍須人工審核。
- 兩組模擬瀏覽器測試通過，涵蓋 320／390／820 寬度。最初因瀏覽器快取路徑未設定失敗，指定既有 `PLAYWRIGHT_BROWSERS_PATH` 後重測通過，未變更正式登入或資料。
- CI 使用明確標記的純色測試圖片；僅驗證檔案結構，不可當成真實社群成品，正式工作流程拒絕這類素材。
- 六張新版插畫、排版 PNG、PDF 與 PPTX 留在私人交付包；未提交公開 GitHub。PDF 為瀏覽器排版預覽，尚未完成 Canva 字型及排版驗證。
- 本次沒有啟用付費 API、IG／FB 發布或生產環境部署。每日自動產圖工具仍未接通；本次圖像是獨立製作，不能宣稱每日自動化已完成。
