# 工作首頁與幫手狀態：介面審核

## 這次調整

保留原有圖示入口與各自的目的頁，讓日常工作入口直接回答：交辦了什麼、是否正在處理、還需要本人決定什麼。

- 「已交辦工作」先列出三項最優先的尚未開始工作；更多項目可以展開查看。
- 「處理中」區分工具正在執行，以及本人手動標記進行中。
- 「等我決定」顯示待看草稿、失敗、退回、等待回覆、範圍或前置工作待確認的任務。
- 「查看這件事」展開對應工作的需求與操作。全部工作、歷史版本、來源及設定仍可查看。
- 已核准的內部草稿不會被算成工作完成；範圍外、歷史與已完成工作不進入上述三個待辦計數。
- 送出後顯示新工作的實際狀態，避免同名舊工作造成錯誤回報；失敗時保留輸入。
- 三個幫手改以能力、實際取得的狀態與下一個動作呈現，連線和排程紀錄收進明細。專案資料可讀取、日曆設定齊全均不被稱為「正在自動工作」。
